Threshold rescoring of stored decider runs

No model was re-run. Each model gets its own threshold τ, set so that p(Yes) ≥ τ on a fixed share of its own moments (the column), because models say Yes at very different base rates. Counting and tutorial questions: respond each time p(Yes) crosses τ upward ("crossing"), or every tick above τ with a 4 s cooldown. Clue-reveal questions: respond the first time p(Yes) ≥ τ, then stop. Scored with the benchmark F1 (±2 s). Baselines: a timer with the same number of responses in each question; one random response for clue reveal; for hit rate, the same number of ticks above τ placed at random. No confidence intervals: read patterns across columns, not single cells. Clue reveal is 7 questions (one question moves its F1 by about 14 points).
